# NewSzxcn Email v1.2.96

## 修复与改进

- 修复微信内阅读邮件时正文链接点击无响应或触发下载的问题。普通邮件与共享收件箱均会移除 `download`，仅允许 `http`、`https`、`mailto` 和 `tel` 链接，并在当前顶层页面跳转。
- 邮件中的远程图片默认阻止加载，用户确认后才显示，减少阅读回执与外部跟踪；邮件 iframe 同时收紧 CSP 和沙箱权限。
- 自动翻译默认关闭，首次启用前明确提示邮件正文会发送至 Google 翻译服务并要求用户确认。
- 登录和两步验证增加账号、IP 与挑战维度的持久化限流；密码修改、管理员/Open API 重置密码及停用账号后会撤销旧会话。
- 创建用户不再允许空密码回退为邮箱账号，并在所有创建/重置入口拒绝密码与登录邮箱相同。新安装必须显式配置管理员密码，明文密码不再写入日志。
- 外部 IMAP 在完成公网地址检查后固定拨号到已验证 IP，TLS 仍校验原始域名，防止 DNS 重绑定绕过私网限制。
- CORS 来源改为严格 URL 校验，并补齐 PUT/PATCH 预检；未配置分享加密密钥时前端禁用操作，API 返回 503。
- 退出失败时保留当前会话并显示错误；修复管理页面语言切换后的标题残留、写信字段标签关联、回复地址解析及邮件刷新状态。
- 优化手机端高级搜索、筛选、写信发件邮箱选择和邮件详情布局。

## 验证与注意事项

- 已通过 Go 全量测试、`go vet ./...`、前端类型检查与生产构建、差异格式检查，以及桌面和 375 x 667 手机视口浏览器检查。
- 微信内置浏览器的最终跳转行为仍受目标站点、微信安全策略和系统浏览器设置影响；升级后需用真实微信设备复核认证链接。
- 升级前备份数据库、部署配置和当前镜像。数据库变更只新增认证限流表，不删除现有邮件数据。
- 回滚时使用上一版镜像并保留当前数据库与邮件目录，不要用旧数据库覆盖新邮件。
