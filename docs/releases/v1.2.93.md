# NewSzxcn Email v1.2.93

## Changes

- Mailbox management adds External Mailboxes immediately after My Mailboxes.
- External accounts owned by the signed-in user are listed together, with search,
  receiving-mailbox selection, status, last-sync and error recovery.
- Failed saves retain the editor; remote-direct accounts cannot invoke local-only
  sync actions. New password-based accounts offer TLS/STARTTLS only.
- Known Maildir paths skip repeated MIME decoding. Unchanged read/star flags no
  longer rewrite database timestamps on each scan.
- Includes the FCM registration, private notification preview and owner-scoped
  mail-change events already used by the deployed Android client. FCM credentials
  remain optional and must never be committed or placed inside an image.

## Limitations

External IMAP remains disabled by default. Configure a durable encryption key
before enabling it. Gmail/Outlook require provider OAuth applications; each external
account requires individual authorization. External SMTP sending and automatic
forwarding of imported mail are not included. Domestic push is not included.

## Upgrade and Rollback

Back up the database using SQLite's online backup and preserve deployment files
and the current image before recreating the mail container. Retain existing FCM
environment variables and read-only credential mounts; the stock Compose file
does not inject private credentials automatically. Use an explicit version tag
for controlled rollout. Recreating the all-in-one container briefly interrupts
HTTP, SMTP and IMAP; keep this maintenance interval short.

Push migration only adds tables, an index/trigger and a default-zero message
column; existing messages are not automatically marked notification-eligible.
On rollback use the previous image and current mail data. Do not restore an old
database merely to roll back binaries, as doing so would discard newer mail.

CPU optimization requires deployment and measurement. No fixed reduction or
end-to-end delivery-time guarantee is made. Companion Android release: 0.2.8.
