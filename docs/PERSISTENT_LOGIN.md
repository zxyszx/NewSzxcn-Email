# App 持久登录

普通会话仍遵循 `LANQIN_SESSION_TTL_HOURS`（默认 168 小时）。登录时明确选择
“在此设备保持登录”后，使用 `LANQIN_REMEMBER_DEVICE_TTL_HOURS`（默认 2160 小时，
上限 90 天）。设置为 0 或不大于普通会话期限可关闭此选项。

登录仍必须通过密码、人机验证和已启用的双因素验证。服务器只保存随机会话令牌
的哈希，客户端使用 HttpOnly、SameSite Cookie，HTTPS 配置下启用 Secure；不保存
用户密码。退出账号撤销当前会话；修改或重置密码撤销该用户的所有会话。

App 默认选择保持登录，网页默认不选择。公开设置中的 `rememberDeviceHours`
用于告知客户端是否支持；新客户端连接旧服务器时不发送新登录字段，避免严格
JSON 校验拒绝登录。此功能没有新增数据库表或字段。

先备份并更新服务端，再安装配套 APK。原有会话不会被延长，已经过期的会话
需要重新登录一次。回滚不会自动撤销已经签发的持久会话；如需撤销，可使用
现有密码重置流程。不要通过清空所有会话的方式强制所有用户退出。

自动检查覆盖普通/持久会话到期、恢复保存 Cookie、退出后重放、改密码后撤销、
MFA 登录及策略上限。Android 进程回收、手机重启与覆盖安装需补充真机验收。
